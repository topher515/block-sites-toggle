# Block Site Toggle

A configurable site blocker that gives you something better to do instead. When you open a blocked site, you get the active **mode**:

- **Focus 🚧**: a nudge, plus how many times you've been bounced today and this week.
- **Fitness 💪**: log push-ups and pull-ups; shows today, last 7 days and ever, with daily goals.
- **Flashcards: Africa 🌍**: name the highlighted country. Multiple choice first, then typing once you know it. Has an "I don't know" button. Spaced repetition decides what comes next.

Counts and progress sync between computers through a small Cloudflare Worker.

## Install (unpacked)

```sh
make build
```

1. Go to `chrome://extensions/`, enable **Developer mode**
2. **Load unpacked** → select `<repo>/build`
3. After pulling changes or editing code: `make build`, then hit the reload icon on the extension card.

The toolbar popup turns block sections on and off. **Mode: … · change…** opens the settings page (mode, mode settings, blocked sites, sync).

`config.json` holds the defaults used on first run. After that, sites are edited on the settings page.

## Sync between computers

The worker lives in `worker/` (Cloudflare Workers + D1, free tier).

```sh
cd worker && npx wrangler login   # once per machine that deploys; opens a browser
make worker-deploy                # creates the D1 database, deploys, writes sync.local.json
make build                        # bakes sync.local.json into this machine's build
```

On another computer, either copy `sync.local.json` into the repo before `make build`, or paste the URL and token into **Settings → Sync**. `sync.local.json` is gitignored. It holds the token.

How it works: every action is an event (`{ id, ts, device, mode, type, data }`) stored locally in IndexedDB. Every 15 minutes (or **Sync now**), the extension pushes unsent events and pulls everyone else's. Events are never edited, so merging is a union. Settings (mode, sites, mode settings) are last-write-wins.

## Adding a mode

Ask an agent, pointing it at `src/modules/AGENTS.md`, or `make new-module NAME=x TITLE="X"`. New flashcard decks are data. See the same file.

## Development

```sh
make test          # unit tests (node --test)
make worker-dev    # local worker on :8787 with a local D1 (token: dev-token)
make worker-test   # smoke-test the local worker
```

Layout:

```
src/core/       store (IndexedDB events), settings, rules (blocking), sync, modes (ctx)
src/modules/    one folder per mode; registry generated by build.js
src/background.js  service worker: blocking rules, sync alarm
worker/         Cloudflare Worker + D1 migrations + deploy script
tools/          one-off generators (Africa map from Natural Earth)
docs/           design notes
```
